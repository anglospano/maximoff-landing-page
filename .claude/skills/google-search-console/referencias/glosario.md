# Glosario de Search Console (en palabras simples)

| Término | Qué significa |
|---|---|
| **Propiedad** | El sitio registrado en Search Console. La nuestra es de tipo *Dominio*: `fundmaximoff.org`. |
| **Verificar** | Demostrarle a Google que el dominio es nuestro (con el registro TXT en GoDaddy). |
| **Registro TXT** | Una línea de texto en la configuración DNS del dominio; Google la lee para verificar. |
| **DNS** | La "agenda" que dice a internet dónde está el sitio, el correo, etc. Se maneja en GoDaddy. |
| **Rastrear** | Cuando el robot de Google (Googlebot) visita una página para leerla. |
| **Indexar** | Cuando Google guarda la página en su "biblioteca" y puede mostrarla en resultados. |
| **Sitemap** | Archivo con la lista de páginas del sitio (`sitemap.xml`) para que Google las encuentre. |
| **Impresión** | El sitio apareció en los resultados de alguien, aunque no le haya dado clic. |
| **Clic** | Alguien entró al sitio desde los resultados de Google. |
| **CTR** | Porcentaje de impresiones que terminan en clic (clics ÷ impresiones). |
| **Posición** | Lugar promedio en que sale el sitio en los resultados (1 = el primero). |
| **Consulta** | Lo que la persona escribió en Google. |
| **Canónica** | La versión "oficial" de una página cuando hay varias parecidas. Va en `<link rel="canonical">`. |
| **Redirección 301** | Mandar a la gente (y a Google) de una dirección vieja a una nueva, de forma permanente. |
| **404** | "Página no encontrada": la dirección no existe. |
| **Core Web Vitals** | Medidas de qué tan rápido carga y qué tan estable se ve la página para los usuarios reales. |
| **HTTPS** | Conexión segura (el candado). Todo el sitio debe ir por HTTPS. |
| **Acción manual** | Un castigo de Google por incumplir sus reglas. Debe estar siempre en "sin problemas". |
| **Fragmento enriquecido / datos estructurados** | Información extra (JSON-LD) que ayuda a Google a entender quién es la fundación. |
| **Google Business Profile** | La ficha de la fundación en Google Maps y búsquedas locales (aparte de Search Console). |
